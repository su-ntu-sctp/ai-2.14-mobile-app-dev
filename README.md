# 2.14 Introduction to Cross-Platform Mobile Application Development

## Lesson Overview

This lesson transitions learners from React web development to mobile development with React Native and Expo. Learners set up a working mobile development environment, run their first app on a physical device and Android emulator, build a simple interactive app using the core React Native components and familiar hooks, and learn to inspect that app with React Native DevTools. The lesson emphasises that the React component model and hooks carry over unchanged; only the UI primitives are new.

## Lesson Objectives

- Explain how React Native differs from React for the web, and how the two share the same component model and hooks
- Set up a React Native development environment using Expo and run an app on a physical device or Android emulator
- Build a basic React Native app using core components (`View`, `Text`, `StyleSheet`) and familiar hooks (`useState`, `useEffect`)
- Debug a running React Native app using React Native DevTools
